# Спецификация: Вкладка Snipe в Auctionator со списками покупок и режимами снайпа

## 1. Общие принципы и среда

- Проект: `Forever Trade` (сервер World of Warcraft: Forever / Era 1.15).
- Доктрина: `Ponytail` (минимальный рабочий дифф, максимальное переиспользование, zero-theater, отсутствие лишних обёрток).
- Дашборд: обслуживается на `http://localhost:10459/dashboard.html`.
- Разделение обязанностей: Код пишется Агентом-Кодером (`addons/ForeverTrade_Sniper/`, `src/`), тесты — Агентом-Тестером (`tests/`).

## 2. Архитектура вкладки Snipe в AuctionFrame

1. **Создание и регистрация вкладки:**
   - Вкладка регистрируется внизу `AuctionFrame` с точным именем `Snipe`.
   - Индекс вкладки: `AuctionFrame.numTabs + 1`.
   - Позиционирование: рядом с предыдущей последней вкладкой через `SetPoint("LEFT", prevTab, "RIGHT", -15, 0)`.
   - Поддержка `PanelTemplates_SetNumTabs` и `PanelTemplates_EnableTab`.

2. **Докинг и управление отображением:**
   - При клике на вкладку `Snipe`:
     - Вызывается `PanelTemplates_SetTab(AuctionFrame, tabIndex)`.
     - Скрываются нативные вкладки аукциона: `AuctionFrameBrowse`, `AuctionFrameBid`, `AuctionFrameAuctions`.
     - Скрываются вкладки Auctionator: `AuctionatorShoppingFrame`, `AuctionatorSellingFrame`, `AuctionatorCancellingFrame`.
     - Главная панель `FTSniperMainFrame` прикрепляется к `AuctionFrame` (`TOPLEFT: 18, -68`, `BOTTOMRIGHT: -18, 36`) без внешней рамки и заголовка перетаскивания.
   - При клике на любые другие вкладки аукциона: `FTSniperMainFrame` гарантированно скрывается.

3. **Стилизация под Auctionator:**
   - Темная тема с полупрозрачной подложкой.
   - Заголовки таблицы: `Вкл`, `Предмет`, `Рыночная цена`, `Потолок выкупа`.
   - Строки списка с иконками, цветовой подсветкой качества (GameFontHighlightSmall / цвета редкости) и тултипами `GameTooltip`.

## 3. Интеграция списков покупок Auctionator

1. **Источник данных:**
   - Чтение глобальной структуры `AUCTIONATOR_SHOPPING_LISTS`.
   - Формат данных Auctionator:
     ```lua
     AUCTIONATOR_SHOPPING_LISTS = {
       {
         name = "Трава",
         items = {
           "\"Глаз мурлока\"",
           "\"Кудрявый лишайник\"",
           "\"Синячник\"",
           ...
         },
         isTemporary = false
       }
     }
     ```
   - Защита от nil: если `AUCTIONATOR_SHOPPING_LISTS` пуст или отсутствует, поддерживается fallback на `FT_SNIPER_CONFIG.targets`.

2. **Санитизация и резолвинг предметов:**
   - Удаление обрамляющих кавычек (`^%s*"(.-)"%s*$`).
   - Очистка расширенных поисковых параметров (например, категорий и фильтров после `;`).
   - Резолвинг ID и иконки через имя предмета, кеш `FT_SNIPER_CONFIG.names` и `GetItemInfo(name)`.

3. **Селектор списков покупок:**
   - Выпадающее меню или кнопки переключения между списками (например, «Все списки» или конкретный список игрока: «Трава», «Расходники»).
   - Быстрый поиск / фильтр по названию предмета.

4. **Элементы управления строки:**
   - Чекбокс: включение/выключение предмета для снайпинга.
   - Иконка + название с интерактивным тултипом по наведению.
   - Метка рыночной цены / себестоимости.
   - EditBox кастомной цены выкупа с поддержкой форматов `Xз Yс Zм`, `500` меди и мгновенным сохранением в `FT_CustomTargets`.
   - Кнопки массовых операций: `Включить все`, `Отключить все`, `Сброс цен`.

## 4. Режимы снайпинга и перенос управления в интерфейс

1. **Режимы работы:**
   - `FT_SnipeMode = "LIST"` (По умолчанию):
     - Снайпятся ТОЛЬКО предметы, присутствующие в списке покупок аукционатора И отмеченные галочкой.
     - Максимальная цена выкупа берется из `customPrice` (если задана) или дефолтной цены отсечения.
     - Любые другие лоты на аукционе игнорируются.
   - `FT_SnipeMode = "ALL"` («Снайпить всё»):
     - Сканирует поток аукциона и выкупает любые лоты, дающие выгоду выше порога `minProfit` (аналог `/fts min`).
     - Порог `minProfit` настраивается прямо в интерфейсе через EditBox.

2. **Элементы управления в заголовке вкладки Snipe:**
   - Переключатель режимов: радиокнопки или кнопки «Только список покупок» / «Снайпить всё».
   - Поле настройки мин. профита для режима «Снайпить всё».
   - Кнопка включения/выключения снайпера: `[ СТАРТ СНАЙПА ]` (зеленая при активности: `[ СТОП СНАЙПЕР ]`).
   - Бейдж статуса: `АКТИВЕН (Список покупок)` / `АКТИВЕН (Все)` / `ВЫКЛЮЧЕН`.
   - Информационная подсказка о колесе мыши для выкупа.

3. **Персистентность:**
   - Сохранение в `SavedVariables`:
     - `FT_CustomTargets`: выбор чекбоксов и кастомных цен по каждому предмету.
     - `FT_SniperSettings`: выбранный режим (`mode`), порог мин. прибыли (`minProfit`), выбранный список (`selectedList`).

  3. Режим `ALL`: фильтрация по порогу минимальной прибыли.
