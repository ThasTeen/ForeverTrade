# Спецификация: Полный редизайн портала Forever Trade

## 1. Архитектурный контекст и философия Ponytail
Проект развивается в строгом соответствии с доктриной Ponytail:
- Никаких избыточных слоев и нагромождений.
- Сохранение одностраничной автономности `portal.html` без необходимости запуска внешних Node/React серверов.
- Zero-theater: честное разделение ролей Кодера и Тестера через отдельных субагентов, запрет на бумажные тесты.

## 2. Устранение дефектов UI и стабильность интерфейса (R06, R07, R08)
- **Устранение жесткого рефреша (R07):**
  - Удалить `<meta http-equiv="refresh" content="30">`.
  - Внедрить мягкий фоновый опрос через JavaScript (fetch текущей страницы или заголовка `Last-Modified` раз в 30 секунд), который обновляет данные только если страница изменилась, сохраняя активную вкладку, позицию скролла, введенный поисковый запрос, состояние чата с ИИ и выбранный элемент инспектора. Если пользователь активно печатает в поиске или чате — обновление мягко откладывается.
- **Исправление тултипа свечей (R06):**
  - В конфигурации Plotly Candlestick задать явный `hoverlabel`:
    ```javascript
    hoverlabel: {
        bgcolor: '#1c2128',
        bordercolor: '#30363d',
        font: { color: '#e6edf3', family: '-apple-system, BlinkMacSystemFont, Segoe UI, sans-serif', size: 12 },
        align: 'left'
    }
    ```
  - Исключить ярко-красный непрозрачный квадрат по умолчанию.
- **Устранение нелокализованных названий и обрезки чипов (R06):**
  - Исключить сырые плейсхолдеры `Item 10xxx` из выдачи селектора и каталога.
  - Починить обрезку текста кнопок быстрого выбора («Остротерн», «Скорополох» с адаптивной шириной flex-wrap).
- **Обеспечение 100% работоспособности всех вкладок (R08):**
  - Проверить обработчики `switchTab` для всех вкладок: Strong Buy, Арбитраж, Дизэнчант, Крафт (Dual), Ящики, Вендор-шаффл, Обзор рынка.
  - Добавить аккуратный empty-state блок при отсутствии записей в таблице.

## 3. Почасовые свечи и аналитика объемов продаж (R09, R10)
- **Почасовые таймфреймы (R09):**
  - Добавить переключатели гранулярности: `1ч` (почасовой срез последних 24–48 часов), `4ч`, `1д` (суточный), `Все`.
  - При почасовой группировке точки цен группируются по $T_{\text{hour}} = \lfloor \text{timestamp} / 3600 \rfloor \times 3600$.
  - Расчет Open, High, Low, Close для каждого интервала.
  - Расчет простой скользящей средней SMA (Simple Moving Average) с отображением сглаженного тренда.
- **Аналитика объемов продаж (R10):**
  - Объем продаж вычисляется на основе оттока лотов между сканами:
    $$\Delta Q_{\text{sold}} = \max(0, Q_{t-1} - Q_t) \quad \text{при} \quad P_t \ge P_{t-1}$$
  - Отображение гистограммы объемов на вторичной оси с бейджем активности рынка.

## 4. Интерактивный диалог с ИИ-рекомендацией (R11)
- **Чат-интерфейс в портале:**
  - Разместить компактный выдвижной / встроенный чат в блоке AI Advisor.
  - Поддержка готовых быстрых промптов: «Что скрафтить прямо сейчас для максимальной прибыли?», «Какие травы растут в цене?», «Какая ситуация с запасами ящиков?».
  - Передача текущего рыночного контекста (топ-3 прибыльных рецепта, цены сырья, спреды) и интеграция с локальным `AntigravityManagerClient` / эвристическим генератором.
  - Сохранение истории сообщений текущей сессии в `sessionStorage`.

## 5. Выбор профессий, база Wowhead Era 1.15 и поисковый движок (R12, R13)
- **База данных по Травничеству и Алхимии (R12):**
  - Полный датасет Classic Era 1.15:
    - Все травы Травничества (Мироцвет, Сребролист, Земляной корень, Магороза, Удавник, Остротерн, Синячник, Дикий сталец, Королевская кровь, Могильный мох, Дикий чеснок, Златошип, Кадгаров ус, Драконьи зубы, Огнецвет, Лиловый лотос, Слезки Артаса, Солнечник, Пастушья сумка, Кровь Грома, Золотой сансам, Снолист, Горный серебряный шалфей, Чумоцвет, Ледяной зев, Черный лотос) с их ID и локализованными именами RU/EN.
    - Все рецепты Алхимии (зелья лечения, маны, защиты, ловкости, силы, эликсиры гигантского роста, львиной силы, настои титанов, ослепляющего света, трансмутации железа, мифрила, арканита) с точными ID, количеством реагентов, требованиями к уровню навыка (1–300) и источником получения (тренер, вендор, дроп).
  - Интеграция в SQLite (`items`, `recipes`, `recipe_reagents`).
  - Выбор профессии в UI (Травничество / Алхимия / Все) с фильтрацией выдачи.
  - Расчет доходности рецепта:
    $$\text{Profit} = P_{\text{AH}}(\text{potion}) \times 0.95 - \sum \text{Cost}(\text{herb}_i) \times N_i$$
  - Подсветка: какой рецепт купить у вендора/тренера и скрафтить прямо сейчас для максимального заработка.
- **Клиентский поисковый движок (R13):**
  - Интеграция быстрого клиентского поиска с поддержкой нечеткого сопоставления (fuzzy search) и префиксного индекса по русским и английским названиям.
  - Автокомплит с выпадающим списком при вводе в поле поиска (Ctrl+K).
  - Мгновенный переход к инспектору и графику выбранного предмета без перезагрузки страницы.

## 6. Независимый аудит 5 агентами (R14)
- По завершении реализации вызвать 5 специализированных субагентов:
  1. `research` / UX Reviewer — проверка удобства, верстки, читаемости графиков и тултипов.
  2. `code-reviewer` — проверка архитектуры, чистоты кода и соответствия стилю.
  3. `security-auditor` — проверка XSS, валидации входных данных и безопасности API.
  4. `test-engineer` — проверка полноты тестового покрытия и крайних случаев.
  5. `web-performance-auditor` — анализ нагрузки на DOM, скорости рендеринга Plotly и плавности обновления.
- Устранить все выявленные дефекты.
