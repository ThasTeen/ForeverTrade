# 12 — Портал: переключатель языка (RU/EN), 1-click копирование и персональные графики по клику

**Требования:** R42, R43, R44
**Зависит от:** 11, 09
**Зона:** `src/dashboard.py` · `tests/test_dashboard.py`
**Волна:** 9
**Ревью:** да — интерфейс
**Модель:** сильная

## Что должно заработать

1. Мгновенный переключатель языка интерфейса и предметов (RU / EN):
   - Кнопка-тумблер `[ RU | EN ]` в шапке `portal.html`.
   - Мгновенное переключение всех элементов UI (заголовки, колонки, бейджи, подсказки) и названий предметов на русский/английский без перезагрузки страницы (на базе `data-ru` / `data-en` атрибутов). Выбор сохраняется в `localStorage`.
2. Быстрое копирование названия предмета (1-click copy):
   - Иконка/кнопка копирования `📋` рядом с каждым названием предмета в таблицах сигналов.
   - По клику копирует название предмета на активном языке в буфер обмена (`navigator.clipboard.writeText`) с всплывающим тултипом `Скопировано! / Copied!`, готовым для мгновенной вставки в поиск внутриигрового аукциона WoW (`Ctrl+V`).
3. Персональный интерактивный график цены на каждый предмет отдельно (Per-Item Dedicated Charts):
   - Вместо перегруженного общего графика из 8 перепутанных линий:
     - Клик по любой строке предмета в таблице (или по кнопке графика `📈`) открывает персональное модальное окно / карточку инспектора для конкретного выбранного предмета.
     - Инспектор строит изолированный график истории цен только для выбранного предмета, показывает средневзвешенную цену, экстремумы (мин/макс) и текущий Z-score.
     - Добавлен фильтр категорий (Trade Goods, Consumables, Weapons, Armor, Waylaid Crates) с быстрым поиском для выбора любого предмета из базы.
