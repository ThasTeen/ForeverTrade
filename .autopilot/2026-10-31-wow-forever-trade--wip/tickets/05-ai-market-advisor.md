# 05 — Интеллектуальный рыночный AI-ассистент

**Требования:** R15, R16, R17
**Зависит от:** 03, 04
**Зона:** `src/ai_advisor.py` · `tests/test_ai_advisor.py`
**Волна:** 4
**Ревью:** нет
**Модель:** сильная

## Что должно заработать

Модуль `ai_advisor.py`, формирующий тактический план действий игрока на сессию:
1. Агрегация компактного JSON-контекста: топ-3 позиции вендорного арбитража, топ-3 маржинальных рецепта под ящики снабжения Waylaid Crates, топ-3 сырьевых товара в глубокой ценовой просадке ($Z \le -1.8$).
2. Интеграция клиента Antigravity Manager для работы с моделью Gemini 3.8 Flash High (вместо Ollama) со структурированным системным промптом.
3. Формирование четкого нумерованного чек-листа оперативных действий (выкуп, крафт, закупка впрок).
4. Встраивание сгенерированного AI-вердикта в верхний промо-блок автономного HTML-дашборда.

## Из брифа, дословно

> «Формирование компактного JSON-контекста (топ-3 вендор, топ-3 крафт ящиков, топ-3 сырьевых просадок)»
> «AI-ассистент рыночной аналитики через Antigravity менеджер (Gemini 3.8) вместо Ollama»
> «Интеграция тактических рекомендаций AI-ассистента в верхний блок автономного дашборда»

## Разделы спецификации

Истории 15–17, Решения §5.

## Критерии приёмки

- [ ] Функция build_compact_context() формирует валидный JSON с топ-3 позициями по каждой из трех категорий
- [ ] Клиент Antigravity Manager успешно валидирует и форматирует запрос к модели Gemini 3.8 и парсит структурированный ответ
- [ ] При отсутствии сетевого подключения клиент использует локальный эвристический генератор рекомендаций без сбоев пайплайна
- [ ] Сгенерированный вердикт встраивается в верхний блок дашборда `build_standalone_dashboard()`
