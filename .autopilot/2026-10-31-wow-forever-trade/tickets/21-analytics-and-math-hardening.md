# 21 — Аналитический движок: исправление математики крафта, Waylaid и фильтрации цен

**Требования:** R71, R72, R73, R74, R75, R76, R90i, R91i
**Зависит от:** 19
**Зона:** `src/analytics.py` · `tests/test_analytics.py`
**Волна:** 15
**Ревью:** да — расчеты
**Модель:** сильная

## Что должно заработать

1. **Waylaid Crates turn-in (Аудит §1):** Стоимость сырья для сдачи ящика NPC рассчитывается строго по 100% рыночной цене аукциона: требовать `p_out > 0` и `target_count * p_out`, без подстановки `min(AH, vendor_buy)`.
2. **Строгий белый список вендорных реагентов (Аудит §2):** NPC-цену разрешено использовать только для предметов, входящих в `VENDOR_REAGENTS_WHITELIST`. Для остальных реагентов использовать только аукционную цену (`P_AH`).
3. **Фильтрация невалидных цен (Аудит §3):** Отсекать `price <= 0` до выборки последнего лота и до формирования статистического окна в арбитраже и Z-score.
4. **Изоляция реалмов при `realm=None` (Аудит §6):** Исключить смешивание цен разных серверов: группировать по `(item_id, realm)` либо явно требовать реалм в выборках.
5. **Мульти-выход рецептов (Аудит §11):** Для рецептов с `expected_yield > 1` делить `pack_craft_cost` на выход и согласованно учитывать аукционный депозит на единицу/лот.
6. **Безопасная перезагрузка overrides (Аудит §19):** Обновлять `_OVERRIDES_MTIME` только после успешного коммита данных в БД; при ошибках возвращать `False`.

## Критерии приёмки

- [ ] Waylaid turn-in считает себестоимость сырья строго как `target_count * p_out` без вендорной подмены
- [ ] Только ID из `VENDOR_REAGENTS_WHITELIST` могут использовать `vendor_buy_price`; дикие ресурсы (рыба, трава) считаются по AH
- [ ] Нулевые и отрицательные цены не порождают торговые сигналы
- [ ] При `realm=None` цены разных реалмов не смешиваются в один арбитражный расчет
- [ ] Рецепты с `expected_yield > 1` корректно масштабируют затраты и депозит
- [ ] Ошибка при загрузке overrides не фиксирует mtime и позволяет повторить чтение при исправлении файла
- [ ] Тесты в `tests/test_analytics.py` подтверждают исправления
