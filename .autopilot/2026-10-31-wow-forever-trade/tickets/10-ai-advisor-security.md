# 10 — Модуль AI-ассистента: санитизация промпта, stdin в agy CLI и устойчивый fallback

**Требования:** R38
**Зависит от:** 08, 05
**Зона:** `src/ai_advisor.py` · `tests/test_ai_advisor.py`
**Волна:** 7
**Ревью:** да — безопасность
**Модель:** сильная

## Что должно заработать

1. Защита от Indirect Prompt Injection: санитизация имен предметов перед включением в промпт (удаление управляющих символов, лимит 64 символа), изоляция рыночных данных тегами `<market_data>`, валидация целевых предметов в ответе LLM по белому списку входного контекста.
2. Защита от переполнения командной строки Windows (`WinError 206`): передача длинного промпта в процесс `agy` строго через `stdin` (`subprocess.run(..., input=prompt, text=True, encoding="utf-8")`) вместо аргумента `-p`.
3. Устранение утечки API-ключа в URL query string: передача ключа через HTTP заголовок `x-goog-api-key` при прямых REST-запросах.
4. Надежный эвристический fallback: безопасные кастинги `_safe_int(val, default=0)` и `_safe_float(val, default=0.0)` при обработке `None` значений в `profit_copper`, `roi` и других числовых полях.

## Критерии приёмки

- [ ] Имя предмета с управляющими символами и инъекциями санитизируется до попадания в промпт
- [ ] Передача промпта в `agy CLI` осуществляется через `stdin`, исключая `WinError 206`
- [ ] REST-клиент передает `api_key` в заголовке `x-goog-api-key` без раскрытия в строке URL
- [ ] Эвристический генератор рекомендаций не падает с `TypeError` при наличии `None` в полях цен и прибыли
