# Спецификация: Биржевые графики, интеграция ProfitCrafter и целевой снайп перекрафта

## 1. Контекст, архитектурный контур и доктрина Ponytail
Пользователь ставит задачу эффективного заработка на перекрафте в WoW Forever:
1. Отслеживать динамику цен на портале `portal.html` как на бирже (японские свечи OHLC, объемы Volume, адаптивность к редким замерам 1-2 раза в день, таймфреймы, линии себестоимости).
2. Подтянуть базу персональных профессий, уровня навыка и изученных рецептов из установленного в игре аддона `ProfitCrafterForever` (`ProfitCrafterForever.lua`), сопоставить с рыночными ценами и рассчитать точный процент прибыли и предельные цены закупки сырья.
3. Модернизировать микро-аддон `ForeverTrade_Sniper`: встроить интерфейс управления прямо в аддон `Auctionator` (подвкладка / панель в окне аукциона), предоставить возможность снайпить только конкретно выбранные предметы с ценой не выше расчетной себестоимости (по умолчанию минимальная цена заработка) или кастомной цены, заданной игроком.
4. Разделение ролей: Агент-Кодер меняет только продакшен-код (`src/`, `addons/`), Агент-Тестер меняет только тесты (`tests/`). Все изменения должны быть минимальными, надежными и подтвержденными тестами без бумаги (Zero-Theater).

## 2. Биржевые графики на торговом портале (`src/dashboard.py`)
1. **Адаптивный биржевой график в инспекторе и модальном окне:**
   - Агрегация снимков цен `price_snapshots` во временные корзины (часовые/дневные свечи OHLC: Open, High, Low, Close).
   - При наличии нескольких замеров в интервале строится график японских свечей Plotly `type: 'candlestick'` с цветовой индикацией (зеленый рост, красный спад).
   - Нижний сабплот гистограммы объемов торгов / плотности лотов (Volume bar chart).
   - Тумблер быстрого переключения режима отображения «Свечи / Линия» (Candles / Line) на панели инспектора. Если сканирования аукциона проводятся редко (1-2 раза в день вечером), линейный график со сглаживанием, маркерами замеров и коридором Min/Mean/Max обеспечивает идеальную читаемость без разрывов.
   - Фильтры таймфреймов: `24H`, `3D`, `7D`, `ALL`.
   - Горизонтальные биржевые уровни: текущая рыночная цена, средняя историческая цена $\mu$, линия безубытка $P_{\text{be}}$ (с учетом 5% комиссии аукциона и депозита) и себестоимость крафта $C_{\text{craft}}$.

## 3. Интеграция с аддоном `ProfitCrafterForever` (`src/etl.py`, `src/analytics.py`, `run_watcher.py`)
1. **Парсинг SavedVariables `ProfitCrafterForever.lua`:**
   - Реализовать функцию `load_profitcrafter_data(wtf_account_path)` для автоматического обнаружения и безопасного извлечения данных персонажей из `WTF/Account/.../SavedVariables/ProfitCrafterForever.lua`.
   - Извлечение словаря `professions`: ID профессии (171: Алхимия, 185: Кулинария, 129: Первая помощь и др.), текущий ранг, максимальный ранг.
   - Извлечение изученных рецептов `recipes`: ID рецепта, название на русском языке, выходной предмет `output`, количество `qty`, список необходимых реагентов `reagents` (ID и количество `n`).
2. **Расчет прибыльности перекрафта и потолка закупки сырья:**
   - Для каждого известного рецепта рассчитать рыночную выручку готового изделия $R = P_{\text{AH}} \times \text{qty} \times 0.95$.
   - Определить предельную цену закупки ключевого реагента $P_{\text{max\_reagent}}$, при которой достигается минимальный целевой профит (по умолчанию ROI $\ge 15\%$ или фиксированная чистая прибыль).
   - Интегрировать рецепты пользователя в конвейер генерации `config.lua` для аддона снайпера.

## 4. Внутриигровой интерфейс аддона снайпера в `Auctionator` (`addons/ForeverTrade_Sniper/ForeverTrade_Sniper.lua`)
1. **Интеграция с окном аукциона и интерфейсом Auctionator:**
   - При открытии аукциона (`AUCTION_HOUSE_SHOW`) детектировать наличие фрейма `AuctionFrame` и вкладок `Auctionator`.
   - Добавить подвкладку/кнопку открытия панели «FT Sniper» в верхней части интерфейса Auctionator (рядом с поиском/списками покупок) с сохранением бесшовного визуального стиля Classic Era.
   - При отсутствии аддона Auctionator панель доступна через кнопку-переключатель или дополнительную вкладку окна аукциона.
2. **Панель выбора предметов и кастомных цен:**
   - Отображение списка целевых предметов перекрафта (название с цветовым кодом качества, русскоязычная ссылка).
   - Чекбокс включения/выключения снайпа для каждого предмета: снайпер отслеживает и выкупает ТОЛЬКО те предметы, напротив которых установлен флаг активности.
   - Поле отображения базового расчетного потолка цены выкупа (дефолтная цена безубытка/прибыли).
   - Интерактивное поле ввода (EditBox) для кастомной максимальной цены: если игрок задает свою цену (например, 80 мед.), снайпер выкупает лоты по цене $\le$ заданной.
   - Сохранение настроек в `FT_CustomTargets` (SavedVariables аддона).
