# 04 — Интерфейс снайпера внутри Auctionator: выбор предметов и цен

**Требования:** R01, R03, R04, R09, R10, R11, R12, R13
**Зона:** `addons/ForeverTrade_Sniper/ForeverTrade_Sniper.lua`
**Волна:** 3
**Зависит от:** 02, 03
**Итог:** Встраивание панели снайпера в интерфейс Auctionator, возможность выбора конкретных предметов перекрафта чекбоксами и задание кастомного потолка цены выкупа

## Что делает Агент-Кодер
1. В `addons/ForeverTrade_Sniper/ForeverTrade_Sniper.lua`:
   - Добавить интеграцию с фреймом `AuctionFrame` и окном Auctionator: подвкладка/кнопка переключения на панель FT Sniper.
   - Создать панель конфигурации снайпера:
     - Список целевых реагентов перекрафта (название с качеством, русскоязычная ссылка).
     - Чекбокс включения/выключения снайпа для каждого предмета (снайпер покупает ТОЛЬКО те предметы, где стоит галочка).
     - Поле отображения расчетного потолка цены выкупа (дефолтная цена безубытка/минимального профита).
     - EditBox для ввода кастомной цены выкупа (если задана, используется она вместо дефолтной).
     - Сохранение пользовательских настроек в `FT_CustomTargets` (SavedVariables аддона).
   - В функции `FT_ScanCurrentPage` проверять:
     - Если предмет не активирован чекбоксом игрока — лот игнорируется.
     - Эффективный лимит цены выкупа берется из кастомной цены (если задана > 0) либо из дефолтного потолка перекрафта.
2. Не изменять файлы в `tests/`.

## Критерии приёмки
- Панель снайпера открывается при взаимодействии с окном аукциона/Auctionator.
- Снайпятся только активированные чекбоксами предметы.
- Кастомная цена переопределяет дефолтный потолок выкупа.
