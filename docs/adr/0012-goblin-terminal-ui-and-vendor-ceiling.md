# ADR 0012: Goblin Terminal UI (100vh), Wowhead Forever Tooltips, Vendor Floor/Ceiling и Shopping List Export

## Статус
Принято (2026-11-01)

## Контекст
Адверсариальный аудит подготовки к запуску сервера WoW Forever 5 ноября выявил необходимость:
1. Защиты от чтения недописанных файлов `Auctionator.lua` при `/reload` клиентом игры.
2. Автоопределения ключа реалма в `AUCTIONATOR_PRICE_DATABASE`.
3. Защиты от ложных сигналов `STRONG BUY` и искажения стоимости крафта товарами NPC, продаваемыми на аукционе с наценкой.
4. Ограничения себестоимости реагентов вендора сверху ценой NPC: $C_{\text{reagent}} = \min(P_{\text{AH}}, P_{\text{vendor\_buy}})$.
5. Добавления категории моментального арбитража `VENDOR_SHUFFLE` ($P_{\text{AH}} < P_{\text{vendor\_sell}}$).
6. Переработки интерфейса дашборда в компактный терминал `100vh` с левой sidebar-навигацией, десктопным CSS grid 65/35 (таблица сигналов и инспектор с единым переиспользуемым графиком Plotly), токенами DeFiLlama, внутренней прокруткой, тултипами Wowhead Forever (`domain: 'forever'`), 1-клик копированием и кнопкой экспорта списка покупок в Auctionator.

## Решение
1. **Debounce и проверка завершённости записи:** В `AuctionatorEventHandler` внедрен 500мс дебаунс со стабилизацией размера и обязательной проверкой закрывающей скобки `}` в конце файла перед вызовом `luadata`.
2. **Автоопределение реалма:** При отсутствии точного совпадения имени реалма в `AUCTIONATOR_PRICE_DATABASE` автоматически выбирается непустой реалм с максимальным числом записей с выводом понятного предупреждения.
3. **Vendor Floor/Ceiling:** Себестоимость реагентов, продаваемых NPC, рассчитывается как $\min(P_{\text{AH}}, P_{\text{vendor\_buy}})$. Если $P_{\text{AH}} \ge P_{\text{vendor\_buy}}$, выдача `STRONG BUY` строго блокируется.
4. **Goblin Terminal UI:** Дашборд `portal.html` скомпонован как терминал на токенах DeFiLlama с левой sidebar-навигацией и десктопным CSS grid 65/35 (100vh):
   - Левая sidebar-навигация: переключение категорий рынка, переключатель RU/EN и горячие клавиши.
   - Основная панель (65%): таблицы сигналов с локальной внутренней прокруткой (`.table-scroll`), мгновенным поиском, клавиатурной сортировкой и разделами (`Strong Buy`, `Арбитраж`, `Крафт Dual`, `Ящики`, `Вендор-шаффл`).
   - Правая панель (35%): инспектор выбранного предмета с внутренней прокруткой, единым переиспользуемым графиком Plotly в палитре темы, линией безубытка и калькулятором сделки.
   - Адаптивность и доступность: responsive breakpoints (1279px, 1023px, 767px) и поддержка `prefers-reduced-motion`.
   - Подключены скрипт тултипов `whTooltips` (`domain: 'forever'`) и `tooltips.js`.
   - Добавлена кнопка «📋 Скопировать Shopping List для Auctionator» (`ForeverTrade^"item1"^"item2"...`).
   - Состояние интерфейса (активная вкладка, поиск, язык RU/EN, выбранный предмет) сохраняется в `localStorage` и бесшовно восстанавливается при 30с автообновлении.

## Последствия
- Полная устойчивость к сбоям записи при `/reload` в игре.
- Отсутствие ложных снайп-сигналов на вендорных реагентах.
- Высокая производительность фронтенда без фризов благодаря единому графику Plotly в инспекторе.
- Быстрый перенос сигналов в игровой клиент через импорт Shopping List в Auctionator.
