# 0010. Отключение перков персонажа Bartering и Master Chef по умолчанию

## Контекст
Серверные перки Наследия `Bartering` (-5% у торговцев) и `Master Chef` (+10% выход кулинарии) были включены по умолчанию (`True`), завышая расчетную рентабельность крафта для начинающих персонажей без открытых перков.

## Решение
Флаги перков `has_bartering` и `has_master_chef` по умолчанию устанавливаются в значение `False` во всех аналитических функциях, контексте AI-ассистента и сборщике дашборда. Их активация переводится в управляемый режим через аргументы командной строки `--bartering` и `--master-chef` в `run_watcher.py`.

## Почему (что рассмотрели и отвергли)
- **Автоматическое чтение состояния персонажа через чтение памяти клиента:**
  Отвергнуто. Проект работает строго в рамках офлайн-анализа сохраненных файлов аддона `Auctionator.lua`, без внедрения в память игрового процесса и без нарушения правил безопасности клиента WoW.
- **Сохранение дефолта `True` с дисклеймером на дашборде:**
  Отвергнуто. Начинающий игрок закупает реагенты у вендоров без скидки по 100% цене и не получает дополнительного выхода готовых блюд, в результате чего рекомендации с дефолтными перками приводили бы к прямым финансовым потерям.

## Последствия
- Базовый расчет себестоимости и окупаемости крафта становится консервативным и безопасным для любого нового персонажа.
- Опытные игроки с прокачанными перками Наследия явно указывают флаги `--bartering` и `--master-chef` при запуске сервиса для разблокировки оптимизированных формул.
