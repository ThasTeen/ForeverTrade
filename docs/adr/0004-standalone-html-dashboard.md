# 0004. Генерация автономного portal.html без локального веб-сервера с Plotly.js

## Контекст
Игроку необходим наглядный визуальный инструмент для принятия торговых решений во время или перед игровой сессией. Дашборд должен отображать:
1. Тактический вердикт и чек-лист действий от AI-ассистента;
2. Таблицу мгновенного вендорного арбитража;
3. Таблицу маржинального крафта под ящики снабжения Waylaid Crates;
4. Таблицу статистических аномалий Z-score;
5. Интерактивные графики динамики цен на ключевые сырьевые материалы и расходники;
6. Цветовую индикацию внутриигровой валюты (золото, серебро, медь).

Одновременно система должна немедленно сигнализировать игроку о появлении редких высокодоходных арбитражных сделок.

## Решение
Реализован генератор автономного монолитного отчета `portal.html` (`src/dashboard.py`):
1. **Автономный HTML5-файл (Standalone Dashboard):**
   Отчет генерируется в виде единого статического HTML-файла, который открывается локально в любом веб-браузере по прямому протоколу `file:///`. Все CSS-стили (включая темную тему под стать интерфейсу WoW) инлайнятся непосредственно в документ.
2. **Интерактивные графики на Plotly.js:**
   Динамика цен на сырье и реагенты визуализируется интерактивными графиками Plotly (`go.Figure`), сериализованными в HTML через `fig.to_html(full_html=False, include_plotlyjs="cdn")`. Пользователь может приближать временные отрезки, скрывать отдельные трейсы и исследовать значения точек при наведении курсора.
3. **Трехблочная структура сигналов:**
   Раздельные визуальные секции с интерактивными таблицами:
   - `Вендорный арбитраж` (покупка лотов с аукциона дешевле цены сдачи вендору);
   - `Крафт под Waylaid Crates` (рецепты для упаковки в ящики с расчетом себестоимости и ROI);
   - `Аномальные сбросы цен` (снайпинг по Z-score с бейджами `STRONG_BUY` и `STRONG_SELL`).
4. **Форматирование валюты (`format_currency`):**
   Конвертация целочисленных значений меди в стилизованные HTML-блоки с классической цветовой кодировкой: золотые (`money-gold`), серебряные (`money-silver`) и медные (`money-copper`) монеты.
5. **Локальные нотификации (`notify_high_value_arbitrage`):**
   При выявлении арбитражных позиций с чистой прибылью более $1\text{g}$ ($10\,000$ меди) система посылает терминальный звонок (`sys.stdout.write("\a")`) и пишет предупреждающее сообщение в лог, привлекая внимание игрока.

## Почему (что рассмотрели и отвергли)
- **Клиент-серверное веб-приложение (FastAPI / Flask + React / Vue):**
  Отвергнуто. Требует постоянного поддержания отдельного фонового процесса веб-сервера, занятия локального сетевого порта, порождает риск конфликтов портов и падений сервиса, нарушая принцип максимальной простоты Ponytail.
- **Экспорт в CSV / Excel:**
  Отвергнут. Не позволяет представить форматированные данные по трем разным моделям в едином окне, лишен интерактивных графиков Plotly и не дает наглядного представления тактического чек-листа AI.
- **Сторонние облачные дашборды (Grafana / Cloud BI):**
  Отвергнуты. Нарушают требование полной изоляции и приватности игровых данных на машине пользователя.

## Последствия
- **Положительные:**
  - Нулевая зависимость от сети и фоновых серверов для просмотра дашборда: файл открывается двойным кликом.
  - Высокая интерактивность благодаря возможностям Plotly.js.
  - Мгновенная реакция игрока на прибыльные сделки благодаря звуковому и консольному уведомлению при арбитраже $> 1\text{g}$.
- **Отрицательные:**
  - Обновление данных требует повторной генерации `portal.html` процессом watcher и обновления страницы в браузере (F5).
