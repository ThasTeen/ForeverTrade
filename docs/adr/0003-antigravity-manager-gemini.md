# 0003. Интеграция с Antigravity Manager (Gemini 3.8 Flash High) с локальным эвристическим fallback вместо Ollama

## Контекст
Рыночному аналитическому агенту требуется интерпретировать совокупность рыночных сигналов (вендорный арбитраж, маржинальный крафт ящиков снабжения Waylaid Crates, просадки цен сырья) и формировать для игрока структурированный тактический чек-лист действий на текущую игровую сессию.

На этапе формирования брифа проекта рассматривались варианты инференса языковых моделей (LLM) для синтеза рекомендаций. Пользователь зафиксировал жесткое требование:
1. Запретить использование локальной Ollama.
2. Использовать стандартизованный клиент Antigravity Manager на базе модели Gemini 3.8 Flash High.
3. Обеспечить работоспособность системы при отсутствии сети или API-ключа.

## Решение
Реализован модуль `src/ai_advisor.py` со следующей архитектурой:
1. **Клиент `AntigravityManagerClient`:**
   Взаимодействует с Google Generative AI REST API (`gemini-3.8-flash-high`) через стандартную библиотеку Python (`urllib.request`), избегая тяжелых внешних SDK. Поддерживает настройку таймаута, переопределение базового URL и чтение ключа из переменных окружения `GEMINI_API_KEY` или `GOOGLE_API_KEY`.
2. **Компактный контекст (`build_compact_context`):**
   Вместо передачи всей базы данных аукциона формируется ультракомпактный срез рыночной ситуации:
   - топ-3 позиции мгновенного вендорного арбитража;
   - топ-3 маржинальных рецепта под ящики Waylaid Crates;
   - топ-3 сырьевых позиций в зоне перепроданности ($Z \le -1.8$).
   Это минимизирует объем токенов, ускоряет генерацию ответа и гарантирует отсутствие галлюцинаций.
3. **Детерминированный эвристический fallback (`generate_heuristic_advice`):**
   При отсутствии API-ключа, ошибках аутентификации, таймауте или сетевых сбоях клиент автоматически и прозрачно переключается на встроенный алгоритмический генератор чек-листа на чистом Python. Он ранжирует действия по приоритетам:
   - Приоритет 1: моментальный вендорный выкуп (быстрая наличность без риска);
   - Приоритет 2: запуск производственного цикла крафта под Waylaid Crates;
   - Приоритет 3: скупка перепроданного сырья по сигналам Z-score под складское хранение.
4. **Интеграция вердикта:**
   Сформированный чек-лист с приоритетами и форматированными суммами прибыли внедряется в верхний баннер автономного дашборда (`portal.html`).

## Почему (что рассмотрели и отвергли)
- **Локальный инференс через Ollama / llama.cpp / GGUF:**
  Категорически отвергнут в соответствии с явным требованием пользователя. Локальные LLM потребляют от 4 до 16 ГБ оперативной и видеопамяти (VRAM), конкурируя за графический ускоритель с запущенным клиентом World of Warcraft, вызывают просадки FPS и требуют сложной установки тяжелых бинарных зависимостей.
- **Тяжелые библиотеки оркестрации (LangChain / LlamaIndex / CrewAI):**
  Отвергнуты по правилам Ponytail. Прямой HTTP-вызов к REST API через `urllib` занимает менее 40 строк кода, не имеет уязвимостей сторонних пакетов и отрабатывает в десятки раз быстрее.
- **Блокирующий отказ при отсутствии сетевого соединения:**
  Отвергнут. Невозможность связаться с облачной LLM не должна лишать игрока тактического чек-листа сессии. Встроенная эвристика обеспечивает 100% доступность интерфейса.

## Последствия
- **Положительные:**
  - Нулевая нагрузка на процессор и GPU рабочей станции игрока.
  - Высочайшая скорость ответа облачной модели Gemini 3.8 Flash High (доли секунды).
  - Бесперебойная работа в офлайн-режиме благодаря детерминированному эвристическому fallback.
  - Минимальные затраты токенов благодаря компактному JSON-контексту.
- **Отрицательные:**
  - Для получения расширенных аналитических комментариев нейросети требуется действительный API-ключ Gemini и интернет-соединение.
