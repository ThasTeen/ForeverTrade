# 0009. Проверка безубыточности выхода при статистическом снайпинге STRONG_BUY

## Контекст
Сигнал снайпинга `STRONG_BUY` выставлялся исключительно по статистическому отклонению ($Z \le -1.8$), приводя к покупке лотов при микроколебаниях цены, где комиссия аукциона 5% и залог делали сделку убыточной.

## Решение
Для выставления торгового сигнала `STRONG_BUY` вводится обязательная проверка реальной экономической безубыточности выхода из позиции. Ожидаемая цена возврата рынка к норме принимается равной выборочному среднему окна $\mu$. Ожидаемая чистая прибыль рассчитывается с вычетом 5% биржевой комиссии аукциона и невозвратного залога: `net_profit = (mu * 0.95) - current_price - deposit`. Сигнал `STRONG_BUY` генерируется только при одновременном выполнении условий: $Z \le -1.8$ и `net_profit > 0`.

## Почему (что рассмотрели и отвергли)
- **Увеличение абсолютного порога Z-score (например, до $Z \le -2.5$):**
  Отвергнуто. При стандартном размере окна $N = 6..15$ в силу неравенства Самуэльсона максимальное отклонение строго ограничено сверху ($|Z| \le \sqrt{N - 1}$), из-за чего экстремальные пороги заблокировали бы все сигналы. Кроме того, на низковолатильных предметах даже $Z = -2.0$ не гарантирует преодоление 5% барьера биржевой комиссии.
- **Учет только 5% комиссии аукциона без аукционного залога (AH Deposit Fee):**
  Отвергнуто. Для дешевых или тяжелых расходников залог за выставление лота ($\max(15, \lfloor V_{\text{sell}} \times 0.05 \rfloor)$) сопоставим с ожидаемой маржой и превращает потенциально безубыточную сделку в чистый минус.

## Последствия
- Полностью устранены ложные рекомендации по скупке товаров при плоских микрофлуктуациях (например, покупка по 96 при среднем 99.33, приносящая убыток после комиссии).
- Количество сигналов снайпинга оптимизировано: отображаются только позиции, гарантирующие реальную положительную доходность при возврате рынка к среднему.
